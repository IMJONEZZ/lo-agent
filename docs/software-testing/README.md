# Software Testing (INFR10057) — Coursework Evidence

This folder holds the evidence for the University of Edinburgh *Software Testing*
course portfolio (semester 1, 2026–7). The software under test is **lo-agent**
(itself), and all evidence for the five learning outcomes lives in this
repository.

> Per the course's option to use a repository other than University GitLab
> ("unless you definitely want to use something different"), this public GitHub
> project serves as both the software and the evidence repository; auditors can
> read everything here without access grants.
